# minions/ — 미니언
- `water/ rock/ fire/` : 원소별 페인팅 그림 `tier0.png`(근접, 칼/곡괭이) `tier1.png`(원거리 마법사) `tier2.png`(공성·보스, 왕관 + 망치). 모두 **오른쪽**을 봄. 흰 배경 원화에서 잘라내고 2px 진한 외곽선 추가 (최대 높이 512px). 예전 그림은 `legacy/art_v1/`.
- `sprite.js` : 게임 화면 표시. 그림을 평면 패널로 세우고 관절 없이 움직임:
  통통 튀는 걷기(스쿼시/스트레치), 이동 방향으로 좌우 반전, 공격 돌진(`swing`), 피격 흰색 번쩍 + 찌그러짐, 사망 팝 + 원소색 파티클,
  발밑 팀 색 링(파랑/빨강), 보스는 더 크게 + 오라.
- 화면 키는 `sprite.js`에서 지정 (월드 단위, 영웅 ≈ 2.2): 근접 1.2(영웅 허리), 원거리 2.05(영웅만큼), 공성 2.85, 보스 3.7 + 오라.
- 팀별 원소는 맵에서 정함 (`maps/meadow.js`의 `teamElem`, 기본: 파랑=water, 빨강=fire).
- 능력치는 `js/data.js`의 `MINIONS`, 이동/전투 행동은 엔진 `js/game.js`.
- 그림 교체: 같은 파일 이름으로 덮어쓰기 (투명 배경 PNG, 높이 512px 이하, 오른쪽을 봄, 발이 그림 아래쪽 끝, 바닥 그림자 없이).

## 부위 리그 (살아 있는 움직임)
- 각 그림을 몇 조각으로 잘라 둠: `minions/<원소>/tier<n>/atlas.png` + `rig.json` (드래곤: `dragons/dragon_rig/`).
  부위: 몸통 / 머리 / 앞·뒷다리 / 무기(팔 포함) / (바위 근접: 반대 팔). 드래곤: 몸통 / 앞·뒤 날개 / 머리 / 아래턱 / 꼬리.
- 자르기: `python3 minions/rig_cut.py [디버그폴더]` (저장소 루트에서, PIL·numpy·opencv 필요). 부위 영역·회전 중심은 `minions/rig_specs.py` (원본 픽셀 좌표).
  앞 부위 밑은 몸통 색을 번져 채우고(inpaint), 뒤 부위는 몸 밑으로 조금 더 넓게 잘라서 돌려도 틈이 안 보이게 함. 그림을 바꾸면 다시 실행.
- 표시: `js/rig2d.js` — 유닛 하나 = 메시 하나(부위별 작은 격자), 매 프레임 꼭짓점만 다시 계산 (텍스처 재업로드 없음, 그리기 1회). 피격 흰색은 셰이더에서 섞음.
- 움직임(`sprite.js`): 걷기(다리 번갈아 + 몸 들썩, 발은 땅에), 숨쉬기, 근접 무기 들어올렸다 내려치기, 마법사 지팡이 들고 끝에서 빛, 바위 공성 주먹 내지르기,
  피격 젖힘, 사망 시 뒤로 넘어지며 사라짐. 불 원소는 머리 불꽃 일렁임, 물 원소는 몸 출렁임.
- 리그를 못 불러오면 예전처럼 그림 한 장으로 표시. 비교용: 주소에 `?rig=0`.
- 뷰어: `minions/viewer.html` (모든 미니언 + 드래곤, 걷기→공격→서기→피격→사망 반복). `?state=walk|attack|idle|hit|death`, `?only=fire/1|dragon`, `?t=초`(멈춤), `?rig=0`.
