# minions/ — 미니언
- `water/ rock/ fire/` : 원소별 페인팅 그림 `tier0.png`(근접, 작은 투구) `tier1.png`(원거리) `tier2.png`(공성·보스, 왕관). 기본 그림은 **오른쪽**을 봄.
- `sprite.js` : 게임 화면 표시. 그림을 평면 패널로 세우고 관절 없이 움직임:
  통통 튀는 걷기(스쿼시/스트레치), 이동 방향으로 좌우 반전, 공격 돌진(`swing`), 피격 흰색 번쩍 + 찌그러짐, 사망 팝 + 원소색 파티클,
  발밑 팀 색 링(파랑/빨강), 보스는 더 크게 + 오라.
- 크기는 `js/data.js`의 `MINIONS.*.h`(근접 40 · 원거리 50 · 공성 78 · 보스 105)에 비례.
- 팀별 원소는 맵에서 정함 (`maps/meadow.js`의 `teamElem`, 기본: 파랑=water, 빨강=fire).
- 능력치는 `js/data.js`의 `MINIONS`, 이동/전투 행동은 엔진 `js/game.js`.
- 그림 교체: 같은 파일 이름으로 덮어쓰기 (투명 배경 PNG, 높이 160px 정도, 발이 그림 아래쪽 끝, 바닥 그림자 없이).
